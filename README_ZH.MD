## 注意事项
请确保在使用前已正确安装和配置 XRay 客户端。
为了保证安全和稳定，请勿将 UUID、私钥等敏感信息泄露给他人。

## 如何寻找合适的 SERVERNAMES 及 DEST

可以直接使用 docker 容器提供的默认值
您也可以自行寻找合适的 SERVERNAMES 及 DEST，请参考 [Reality - TLS - Scanner](https://github.com/XTLS/RealiTLScanner) 及[已知可用列表](reality/SERVERNAMES_ZH.MD)
